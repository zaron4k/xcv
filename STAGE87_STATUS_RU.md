# Stage 87 — индивидуальные результаты слияния

Версия: **0.79.0** · Minecraft 1.20.1 · Forge 47.4.28 · Java 17.

## Реализовано

- Вместо одного детерминированного ID для одинакового рецепта каждый ритуал выдаёт собственный экземпляр результата.
- Генератор добавляет случайную особенность и категорию редкости.
- Теги компонентов наследуются; исходные компоненты остаются у игрока.
- История происхождения сохраняется отдельно в `fusionHistory` внутри персональных данных игрока.
- Уникальный ID строится из владельца, счётчика ритуалов, seed и базового рецепта; ID остаётся допустимым для внутреннего каталога.

## Проверено

- Чистые Java-классы генератора скомпилированы `javac`.
- `FusionOutcomeGeneratorSmokeTest: PASS`.

## Не проверено

- Полная компиляция Minecraft/Forge-классов.
- Проверка нового результата в клиентском GUI и реальная загрузка/перезапуск мира.
- Forge-сборка не заявляется успешной в отсутствие подтверждённого запуска Gradle.
